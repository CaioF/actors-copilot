# Personal DNA, vault and acting coach

## Personal DNA chat

**Entry and layout.** Sidebar Personal DNA opens `/chat`, a standalone layout with Back to Dashboard, chapter navigation and conversation. A production Economy session showed “Continue your discovery”, “Personal DNA Extraction”, four chapter controls (Foundation & Persona, World & Relational Power, Inner Shadow & Vulnerability, Core Fuel & Creative Drive), How DNA Extraction Works and Upload Baseline. This was a page load, not a completed conversation.

`/personal-dna` is a separate placeholder page in the mapped source: its “Start Building DNA” button has no handler there. The sidebar points directly to `/chat`; verify current behavior before treating the placeholder as a working navigation path.

**Drive.** Choose a chapter in the sidebar; inspect the active chapter and its progress. Enter a synthetic message in the textarea (`Ask me anything...` in the observed state); the main button changes its accessible name from `Start recording` to `Send message`. Submit, wait for assistant content and enabled input, then navigate away and reopen. Confirm the specific user message and response persist in the intended session; test errors and retry separately. Shortcuts include Change the subject, I don't understand the question and End Session; they can send messages or mutate session state, so exercise on a disposable identity. The help modal and DNA Reservoirs control should open/close without sending. Attach file and baseline uploads send content to processing services; use synthetic documents only. Recording requires permission and transcription services; test denial, stop and failure independently.

**State and boundaries.** `hooks/use-chat.ts` subscribes to `users/{userPath}/dnaSessions/{sessionId}` and messages, and stores tracker state in localStorage; a fresh browser context and a reload test different persistence boundaries. DNA endpoints include `/api/dna/chat`, `/baseline`, `/synthesize`, and transcription. AI response, extraction, vault entry and synthesized profile are distinct outcomes; do not infer one from another. Check `components/chat-input.test.tsx`, `components/chat-messages.test.tsx`, `lib/dna/extraction/` tests and source when relevant.

**Observed, 2026-11-17.** Production, Chrome 157 headless, 1440×900, Economy test account and seeded real session: typing a synthetic message produced an HTTP 200 and an assistant response; after the processing control became enabled, both messages were visible after reload. An earlier run reloaded before processing finished and failed the reload check; that was insufficient evidence of a product defect. Synthetic messages remain in the test account. Keyboard typing mattered: Puppeteer's `fill` left visible text without changing the controlled Send action in this run. This did not establish an extraction or a vault update.

## DNA Vault

Open `/dna-vault`. Production Economy showed “Personal DNA Vault”, Refresh, Export and Extract More DNA; data-dependent tabs may appear after loading. Source provides Overview, Insights and Memory tabs; populated Insights has section filters and `Filter deductions...`, Memory has section filters and `Search actor quotes...`, both with Clear search. Test empty/error/populated states and confirm filtering is reversible; Refresh fetches data and Export calls print, not a persistent database export. The empty state links to `/chat`. Verify a new extraction independently of the chat response. Source: `app/(interior)/dna-vault/page.tsx`, `components/dna-vault/`.

Observed 2026-11-17 in production, Chrome 157 headless at 1440×900, using the seeded Economy test session: the populated vault opened all three tabs. Insights and Memory each contained entries; a synthetic nonmatching search showed the corresponding no-match state, and Clear search emptied each input. This did not verify the correctness of the entries, section filters, Refresh, Export or a new extraction.

## Acting Coach

Sidebar → `/acting-coach`. Active Economy is routed to `/upgrade`; this was observed in production with a seeded real session. Business coverage requires a real Business test subscription and cannot be inferred from Economy. With a suitable account, start a session, use quick prompts, send a synthetic message, verify loading/disabled input, response and citations where applicable, then reopen the correct history item. New Session should not overwrite the old one. Audition detail can pass search parameters and trigger a linked coaching prompt; verify one trigger and correct audition after reload. Source: `app/(interior)/acting-coach/page.tsx`, `hooks/use-acting-coach.ts`, `app/api/coach/chat/`, `lib/acting-coach/`. Coach sessions/messages persist under `users/{userPath}/coachSessions`; tests include `hooks/use-acting-coach.test.tsx`, `app/(interior)/acting-coach/page.test.tsx`, `app/api/coach/chat/route.test.ts`. Except marked observations, scenarios are source-derived and not a provider/browser pass.
