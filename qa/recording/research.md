# Recording decisions

The first showcase split referral entry, plan selection and Stripe labels across different clips and accounts. Switching tabs on the login form demonstrated a control, but it did not demonstrate signup. The replacement requires one new account, one fresh browser context, the operator's displayed link, the application's trial redirect, the hosted order summary and the same member in admin. The only payment substitute is the protected demo confirmation in [PR #115](https://github.com/CaioF/actors-copilot/pull/115).

Every included report records its origin and outcome. The affiliate acceptance check also requires the browser's HTTP 303 from the demo endpoint and verified cleanup. The native checkout order summary is shown in place, with unrelated payment and member information masked. Live actor runs use the UI sign-in form. A scripted Coach fixture remains useful for CI and has a separate evidence type.

Record at 1440 × 900, 30 fps and English locale. Provide enough time to identify the selected control and resulting text. Preserve the original screen capture even if a labeled chapter edit shortens an analysis wait. Decode the finished file and check representative frames for readable headings, the discount, the correct member and privacy. An observed checkout amount does not establish that Stripe created a subscription, sent a webhook or paid a commission.
